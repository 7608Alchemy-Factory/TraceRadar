# MCD 同篇多优惠 Event 边界提示词试验

## 规则

根据冻结的 MCD 标准答案，MCD-03 是一篇来源，但包含两项可分别追踪的优惠：套票换购券可在 2026-11-09 或以前使用，茶饮优惠在 2026-10-02 结束。套票停止发售日未明，不能把换购券使用截止日说成发售截止日。每篇来源数仍为一。

最终保留的 `assessment-v14` 提示词要求：默认将同一命名活动或产品的每日优惠、附属优惠和券条款归入一个 Event；只有明确存在**两项独立优惠，且有两个不同的明确结束或使用截止日期**，才拆成两个 Event。不同开始日期、未知截止日期及每日优惠日历均不足以触发拆分。换购券的使用截止日可作为后续更新节点，但不推断未明示的发售截止日。
