转场参数

  • 概览使用 ScrollTrigger 驱动同一个雷达标记。定位以窗口高度的 56% 为参考，按各段位置计算。段落标题和内容在进入视口时错峰 65 ms，单项 480 ms。
  • 工作视图共享一个标签下划线，320 ms 内移动至目标。正文同步在 360 ms 内落位。键盘可用左右键、Home 和 End 切换。
  • 事件抽屉水平移入，表单和证据弹层垂直移入，均为 280 ms。遮罩独立淡入 240 ms。手动关闭时沿原方向退出，耗时 170 ms。
  • 窄屏使用静态定位点。开启减少动态效果时保留静态图盘、标签和全部入口。
  • 标题和拉丁界面文字用 Host Grotesk，数字与时间戳用 IBM Plex Mono，中文回退到系统无衬线字体。

动效参考 Codrops · Consecutive Scroll Animations with One Element。字体参考 Fontesk · Host Grotesk 和 IBM Plex。
