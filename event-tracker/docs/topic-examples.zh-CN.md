# TraceRadar 主题示例

30 个配置覆盖 15 类，每类两例。首页在「主题类型」选择类别，再点下方「主题示例」。表单会预填主题名称、追踪目标、类型和逐条排除规则。类型从左到右就是优先级，第一项决定示例分组与封面。表单下方可展开推荐检查、通过标准和验收样例。按下「创建主题」后，再为自己的主题批准来源。

## 科技

### 1. 从试点到上路：香港自动驾驶接驳

- **追踪目标**　跟进香港机场、园区及公共道路的自动驾驶接驳项目。按运营方和线路分别建档，记录试验牌照、试行区域、载客条件、班次及开放对象。区分封闭测试、限定载客试行与公众常态服务，核实首日、站点和预约方式。
- **主题类型**　科技、出行、民生
- **排除规则**
  - 香港以外的自动驾驶演示
  - 车企融资和估值
  - 缺少可识别运营方或线路的宣传
  - 普通人工驾驶机场接驳
- **推荐检查**　真实模型手动检查，再用 Agent 复查。批准运输部门公告及机场或营运方网页
- **通过标准**　同线路从封闭测试到限定载客在同一事件推进。另一条线路分档，海外试玩排除
- **验收样例**　交通机构公布 A 线封闭测试后，营运方确认同一线开放预约试乘。合并为一条时间线，在首次公众开放一栏标出证据；另一园区线路另建事件。

### 2. 大模型推理接口上线与退役

- **追踪目标**　跟进选定模型服务的正式 API 变动。为每个模型和地区记录模型 ID、公开或预览状态、上下文与工具能力、价格、限额及停用时间。将公告、实际开放、价格生效和旧接口退役记为独立节点。
- **主题类型**　科技、财经
- **排除规则**
  - 匿名跑分与缺少可复现版本的性能榜
  - 消费端聊天网页的皮肤更新
  - 第三方转售折扣
  - 缺少模型 ID 或生效时间的传言
- **推荐检查**　网页监测建立基线，真实模型手动检查，结果稳定后每天定时
- **通过标准**　模型 ID 与地区匹配，预览和正式可用分阶段，旧型号的退役日期有原文
- **验收样例**　同一推理模型先公布预览，再开放香港区域调用，随后公告旧模型将退役。前三个时间点各自记录，退役另挂旧模型 ID；价格以对应地区价目表为准。

## 教育

### 3. 大学课堂的生成式 AI 规则

- **追踪目标**　跟进香港高校与院系公开发布的生成式 AI 教学及评核规则。记录适用课程和学期、允许的用途、披露要求及学术诚信处理。把学校通则、院系细则与课程实例分开，标记征询、公布和正式实施。
- **主题类型**　教育、科技
- **排除规则**
  - 学生个人经验帖
  - 与课程无关的企业培训
  - 缺少公开规则的教师个案
- **推荐检查**　真实模型手动检查，批准学校指引和院系公告，规则互相覆盖时启用 Agent
- **通过标准**　学校通则和课程细则分开，适用学期与允许操作能追溯，个人评论不触发更新
- **验收样例**　大学公布通则后，某院系发布下一学期细则。各自记录适用层级；课程允许用于改写的条文保留用户范围及披露要求。

### 4. 香港中学电子学习资助与设备借用

- **追踪目标**　按学年记录电子设备资助、借用计划及配套网络支援。提取适用学校与学生、申请窗口、资助上限、设备归属及归还要求，区分全港政策、个别学校安排和机构捐赠。
- **主题类型**　教育、民生
- **排除规则**
  - 零售商折扣
  - 个人二手设备交易
  - 大学研究补助
  - 与学习设备无关的助学金
- **推荐检查**　真实模型手动检查后每周定时，批准学校或资助方公开网页
- **通过标准**　核对申请窗口、对象及设备归属，不把单校捐赠归入全港资助
- **验收样例**　一所中学发布设备借用安排并延长申请期。把新截止日期写入同一条记录，另有其他学校获设备捐赠时独立归档。

## 出行

### 5. 一站能不能用：港铁无障碍路线复原

- **追踪目标**　按车站和出入口记录升降机加装、临时停用、预计复修及实际复用。记录受影响的行人路线、可用替代路径、服务范围及恢复时间，尤其关注宣布完工但入口仍有限制的情况。
- **主题类型**　出行、民生
- **排除规则**
  - 普通车务延误
  - 电梯品牌宣传
  - 无法定位到车站的投诉
  - 未影响通行的例行检查
- **推荐检查**　真实模型手动检查，选一个车站做定时；有历史复修报道时启用 Agent
- **通过标准**　同一出入口的停用、延期和开放能串起来，其他站点单独归档
- **验收样例**　同一车站 B 口先停用、后延期、最终恢复。每个状态带原公告日期，并用一条其他出入口维修稿测试独立归档。

### 6. 夜间过海交通何时加班

- **追踪目标**　跟进大型活动和节日期间的夜间过海安排，按路线及日期记录临时尾班、加班班次、改道、上客点和费用。区分建议、官方安排、当晚调整和事后恢复。
- **主题类型**　出行、文化、民生
- **排除规则**
  - 不涉及过海的日间班次
  - 旅行攻略
  - 只有现场照片的报道
  - 没有日期的转发
- **推荐检查**　真实模型手动核验后，在活动前、开场当晚、完场前设三次检查
- **通过标准**　同一夜间路线的尾班与临时改道可关联，次日或不同路线分开
- **验收样例**　同一场活动公布夜间尾班延长，当晚又临时更改上客点。更新原档并保留原上客点，不同日期的加班另立档。

## 科学

### 7. 从发射到交付：月球任务进度

- **追踪目标**　以任务和载荷为单位跟进发射窗口、入轨、着陆、通信恢复、科学观测及公开数据交付。优先采用任务团队与航天机构发布，分开记录预计、尝试、部分成功与官方复核。
- **主题类型**　科学、科技、国际
- **排除规则**
  - 太空题材影视
  - 没有任务名称的概念图
  - 重发旧发射视频
  - 仅讨论运载商估值的报道
- **推荐检查**　真实模型 + Agent，批准任务方和航天机构；把已公告窗口转成指定时间点
- **通过标准**　延期与发射成功分辨，时间戳和任务身份稳定，未经确认的传闻不改变结论
- **验收样例**　任务团队宣布延后发射，之后确认入轨，载荷方发布首批数据。按任务 ID 连接节点，新闻中的预计与机构确认分开。

### 8. 珊瑚热浪之后的复原验证

- **追踪目标**　追踪选定香港水域的珊瑚白化、恢复及监测。按站点和调查周期记录水温异常、观测方法、影响比例、复测结果和修复计划，区分目击、定量监测和同行评审。
- **主题类型**　科学、环境
- **排除规则**
  - 水族交易
  - 不涉及指定水域的潜水游记
  - 缺少海域或日期的照片
  - 重复引用同一组观测数据
- **推荐检查**　真实模型手动检查，人工提交两期同站点监测报告做对比
- **通过标准**　同站点和同指标才能比较，其他水域及照片转发不会生成状态变化
- **验收样例**　同一站点两次调查用同一种白化比例口径。时间线可比较两次比例；不同站点的照片不得触发该站结论。

## 饮食

### 9. 校园与社区餐饮改用可重复餐具

- **追踪目标**　按校园、场馆或餐饮商记录可重复餐具的试点、推广、押金、归还点、洗涤安排和减废结果。把试点期、扩展期和暂停分开，并核对不同照片或新闻是否报道同一试点。
- **主题类型**　饮食、环境、教育
- **排除规则**
  - 一次性纸具带货
  - 未公布归还或洗涤流程的宣传
  - 家庭餐具推荐
- **推荐检查**　真实模型手动检查，稳定后每周定时
- **通过标准**　同试点的押金和回收点更新关联原档，其他场馆分开
- **验收样例**　同一校园先试行两处归还点，后来公告增至五处。保留适用餐厅及押金条件，另一校区的公告单独归档。

### 10. 香港预包装食品召回与结案

- **追踪目标**　以品牌、产品和批次为单位记录公开召回通知、风险类型、销售区域、退换方式、范围扩大与结案。以食物安全部门及生产商的公开通告为主要依据，同一批次的更正保留原时间线。
- **主题类型**　饮食、健康、民生
- **排除规则**
  - 个人食评
  - 未经核验的病例贴文
  - 与香港销售或进口无关的召回
  - 餐厅评级
- **推荐检查**　真实模型手动核验，批准食安部门和生产商，随后按事件密度定时
- **通过标准**　同批次的范围修订与结案关联，同品牌其他批次分离，最终以发布机构为依据
- **验收样例**　品牌宣布批次 X 召回后，监管方扩大销售门店范围。更新批次 X，同品牌批次 Y 保持独立，行动指引链接到通知原文。

## 法律

### 11. AI 生成内容的版权裁决与申诉

- **追踪目标**　按司法管辖区和案号追踪已公开、直接讨论生成式 AI 训练或输出的版权案件。记录程序节点、涉争问题、裁决范围、上诉或和解，并区分法院确认、当事方主张和媒体解读。
- **主题类型**　法律、科技、国际
- **排除规则**
  - 没有案号的舆论争议
  - 律师营销
  - 未公开聊天记录
  - 只讨论商用模型价格的内容
- **推荐检查**　真实模型 + Agent，采用法院文件和当事方正式公告
- **通过标准**　同案号串起裁决和上诉，法院结论与当事方说法有明确区别
- **验收样例**　法院发布一审裁决，被告随后提交同案上诉。原裁决与上诉状态同时可查；当事方声明中的未确认法律主张标为主张。

### 12. 香港立法中的消费者订阅与自动续费

- **追踪目标**　跟进香港有关自动续费、取消流程和价格披露的官方咨询、修订和执法指引。按提案或规则分别记录草案、通过、生效及行业宽限期，提取对商家与消费者的具体适用范围。
- **主题类型**　法律、民生、财经
- **排除规则**
  - 没有正式出处的法律解读
  - 普通促销
  - 无新进展的旧稿重发
  - 与订阅收费无关的个别退款
- **推荐检查**　真实模型手动检查，跟踪咨询和议会文件；公开审议日期可设具体时间点
- **通过标准**　通过、生效和宽限期分别记录，普通市场活动排除
- **验收样例**　选定一项建议，顺序提交咨询文件、修订稿和生效公告。最终状态区分表决日期、生效日期及适用行业。

## 体育

### 13. NBA 转会传闻到官方注册

- **追踪目标**　按球员与交易对手分别追踪选定球队的谈判、口头协议、官方签约、体检与交易完成。记录关键条款的消息来源及可信度，保留记者报道与球队公告的冲突，区分续约、签约和多方交易。
- **主题类型**　体育、财经
- **排除规则**
  - 与转会无关的比赛统计
  - 球迷自制交易方案
  - 没有新证据的旧消息引用
  - 球鞋代言
- **推荐检查**　「测试离线回放」选择 LBJ 逐日语料或 NBA 多事件语料，真实模型分阶段跑，后几阶段启用 Agent
- **通过标准**　记者消息、签约确认和独立交易能区分。重复或冲突输入不会自动变成第二个重大进展
- **验收样例**　将记者爆料、球队声明、联盟交易确认按时间输入。同一交易逐步推进；换队对象不同或另一球员的续约建立独立事件。

### 14. 香港马拉松：报名、路线与延赛

- **追踪目标**　按届次及项目记录报名阶段、抽签结果日期、名额和资格、路线变更、交通安排以及天气触发的延赛与退款。将某一组别的变化留在该组别的时间线。
- **主题类型**　体育、出行、环境
- **排除规则**
  - 个人训练计划
  - 装备测评
  - 非指定赛事
  - 未经赛事方确认的封路传闻
- **推荐检查**　真实模型手动核验后，在报名、抽签和赛前各设一次检查
- **通过标准**　本届不同组别、报名窗口和改期能分开，官方信息覆盖未经确认的日期
- **验收样例**　赛事方公布全马路线后调整半马出发时段。两组别更新各归其档，受影响道路和时间附在对应比赛记录。

## 优惠

### 15. 电影节青年票真的怎么买

- **追踪目标**　跟进选定香港电影节的青年票、学校配额、会员优先购及候补返票。按活动记录优惠对象、票价、核验方式、开售和截止时间，保留售罄、加场和退款变化。
- **主题类型**　优惠、文化、教育
- **排除规则**
  - 黄牛转卖
  - 会员推荐链接
  - 未明确适用电影节的常驻影院折扣
  - 过期团购
- **推荐检查**　真实模型手动核验官方票务页，在开售前、开售时和加场公告后检查
- **通过标准**　同场次的资格、售罄和加场可辨，黄牛和推荐链接被跳过
- **验收样例**　同一影片首场青年票售罄，主办方随后增开一场。分别记录开售及售罄时间、票种资格和加场日期。

### 16. 超市生鲜同规格优惠与会员门槛

- **追踪目标**　跟进指定香港超市公开的限时生鲜优惠。按零售商、商品规格和活动周期记录标价、单位价格、会员门槛、换购条件、渠道和适用门店，区分新申请优惠、活动延续与商品规格变化。
- **主题类型**　优惠、饮食、民生
- **排除规则**
  - 无法查验的个人收据传闻
  - 第三方推广码
  - 没有净重或件数的优惠宣传
  - 无法核实活动日期的清仓转帖
- **推荐检查**　手动提交两份同规格价单，使用真实模型，再启用每日定时检查
- **通过标准**　单价、单位、促销日期和门槛一致才可比较。规格变更可见
- **验收样例**　以同一家超市、同商品和同包装规格的两张价单为例。新增会员门槛算一项进展，包装换成另一规格要注明不可直接比较。

## 时政

### 17. 香港公共空间咨询怎样变成施工

- **追踪目标**　跟进指定区内海滨、行人空间或公园改造。按项目记录咨询、区议会或立法会文件、预算审批、招标、施工及交付，并提取争议点在哪次会议或修订后改变。
- **主题类型**　时政、民生、环境
- **排除规则**
  - 与项目范围无关的政论
  - 缺少正式出处的评论
  - 其他区的类似工程
- **推荐检查**　真实模型 + Agent，批准议会、招标和施工公告
- **通过标准**　相同工程编号连接咨询、预算和施工。其他工程不会串入
- **验收样例**　议会通过预算后公布同编号工程招标。将预算与招标录入原项目，并保留咨询里尚未采纳的主要条件。

### 18. 电子政务服务扩大覆盖的进度

- **追踪目标**　按具体服务跟进新增网上申请、试点部门、资格、身份验证方式、生效日期及线下渠道安排。按官方来源区分功能发布、地区或部门扩围、系统异常和恢复。
- **主题类型**　时政、科技、民生
- **排除规则**
  - 软件供应商行销
  - 只更新网页外观的发布
  - 范围外的离岸服务
  - 未经证实的个别账号问题
- **推荐检查**　真实模型手动检查，稳定后定时监测服务状态页
- **通过标准**　哪个部门扩围、何时开始和恢复均有证据，网页换肤不改变服务状态
- **验收样例**　某网上申请先试点两个部门，再由官方公布新增部门。保留适用范围和开始日期，官网改版稿不触发新的状态。

## 民生

### 19. 街市翻新后，摊档去哪里

- **追踪目标**　跟进指定街市翻新、临时搬迁及重开。逐市场记录停业范围、临时摊档地址、租金安排、无障碍动线、预计和实际重开日期，核对部分重开和全面恢复的差别。
- **主题类型**　民生、饮食、出行
- **排除规则**
  - 商场周年活动
  - 个人摊档食评
  - 未经证实的拆迁图
  - 与指定街市名单无关的零售消息
- **推荐检查**　真实模型 + Agent，用政府公告及实际开放报道做时序对照
- **通过标准**　部分开放和全面恢复区分，确切搬迁地址及影响范围可核对
- **验收样例**　政府公告街市短期迁往临时点，随后两个楼层分期重开。记录仍留在临时点的摊档，并保留全场复业的待确认日期。

### 20. 公共图书馆夜间服务与自助还书

- **追踪目标**　按分馆或站点记录延长开放时间、自助还书机试点、覆盖范围、维护停用和恢复。提取实际使用条件、账户要求和截止时间，区分节日临时安排与长期调整。
- **主题类型**　民生、教育、文化
- **排除规则**
  - 商业书店促销或活动
  - 一般新书推荐
  - 与开放或自助服务无关的意见
- **推荐检查**　网页监测先保存基线，再用真实模型检查公告变化
- **通过标准**　单个分馆或站点的维护和恢复相连，不把节日临时安排当长期规则
- **验收样例**　分馆宣布延长周五开放时间，另有自助还书机因维修暂停。两种服务分档，节日临时安排只覆盖明确日期。

## 国际

### 21. 跨境电子支付互通到哪一步

- **追踪目标**　按地区组合与支付网络跟进试点、商户范围、参与钱包、交易币种、限额、费用和实际开放日期。区分签署合作备忘录、少量试点与面向公众上线。
- **主题类型**　国际、财经、科技
- **排除规则**
  - 外汇走势预测
  - 推广返现
  - 未经证实的商户接入名单
  - 不涉及互通功能的投资报道
- **推荐检查**　真实模型 + Agent，选择双方官方公告并按地区组核验
- **通过标准**　备忘录、试点与实际开放分阶段，明确限额和支持钱包
- **验收样例**　两地支付方先签备忘录，后公布试点商户及面向公众的正式日期。记录钱包、币种和限额，测试返现广告不影响状态。

### 22. 跨国博物馆借展与文化遗产归还

- **追踪目标**　按馆藏编号或明确对象跟进公开的借展、归还协商、协议签署、运输、交接与展出变动。记录原持有方、接收方、期限以及官方文件确认的状态。
- **主题类型**　国际、文化、法律
- **排除规则**
  - 拍卖价格
  - 无法确认馆藏对象的传闻
  - 泛泛的馆藏介绍
  - 没有交接进展的纪念报道
- **推荐检查**　真实模型手动检查，加入新旧馆方公告，必要时开启 Agent
- **通过标准**　同一馆藏对象的签署、交接和展出相连，拍卖新闻与同名物品排除
- **验收样例**　两家博物馆发布关于同一馆藏编号的协议与实际交接公告。区分借展期限和最终归还，另一个同名作品不应合并。

## 财经

### 23. 上市公司并购从报价到交割

- **追踪目标**　记录一宗公开并购的首次披露、竞价或改价、股东表决、监管决定、截止期、交割与终止。优先核对交易所披露和监管公告，为不同买家或标的分开建档。
- **主题类型**　财经、法律、国际
- **排除规则**
  - 目标价预测
  - 日常股价变动
  - 没有披露文件支持的匿名猜测
  - 无关的同行业并购
- **推荐检查**　真实模型 + Agent，批准交易所或监管披露
- **通过标准**　不同标的、买家和报价拆分，关键批准条件与交割状态有出处
- **验收样例**　同一交易先披露报价、后提高报价，监管有条件批准。将批准条件、股东表决和实际交割状态分开。

### 24. 香港公共事业收费怎样调整

- **追踪目标**　跟进指定公共事业公布的基本收费、附加费、补助和宽限期。记录适用用户、计算方式、提交或批准时间与账单实际生效日，区分方案调整、一次性补助和长期费率变化。
- **主题类型**　财经、民生、环境
- **排除规则**
  - 个别账单争议
  - 其他地区的收费
  - 替代产品广告
  - 只有宏观预测的文章
- **推荐检查**　手动提交方案和正式账单说明，用真实模型检查；生效日期可设定时点
- **通过标准**　一次性补助和基础费率分开，知道费用何时实际生效
- **验收样例**　公用事业同时公布新基础费率和限时补助。报告分别列出生效日与结束日，再用相同服务下另一用户档位验证适用范围。

## 环境

### 25. 极端降雨：预警到交通恢复

- **追踪目标**　按一次天气过程关联公开预警、受影响区域、停课或交通限制、预警解除及服务恢复。保留时间顺序与适用范围，对多区报道去重，同时保留安排有差别的地区。
- **主题类型**　环境、出行、民生
- **排除规则**
  - 时效已过的天气图重发
  - 未经核实的个人天气推测
  - 香港以外的类似天气
  - 没有地点和时间的现场视频
- **推荐检查**　选择一个历史天气过程，用真实模型手动提交时间化证据，并验证定时设置
- **通过标准**　同一过程的预警、限制和恢复按时间排列，不同区域可保留差异
- **验收样例**　用一次降雨的预警、交通中断和分区恢复公告作顺序输入。保留每区适用时间；重复报道不抹掉恢复时刻的差异。

### 26. 屋苑厨余回收从试点到常态

- **追踪目标**　按屋苑跟进回收点启用、收集时段、准入条件、处理量和设备故障。记录试点是否扩展、移动点是否撤换，并区分项目累计量、分点数量和日均数据。
- **主题类型**　环境、民生、科技
- **排除规则**
  - 普通家庭食谱
  - 没有屋苑或站点名称的宣传
  - 旧设备投放消息重复发布
  - 没有实际部署的技术新闻
- **推荐检查**　网页监测 + 真实模型，每周定时前先验证两次变化
- **通过标准**　同屋苑启用和故障相连，累计量和日均口径区分，无项目的技术新闻排除
- **验收样例**　屋苑新增回收点后，运营方对其中一台设备发布维修通知。更新对应点位，用同一时间范围的运营数据检查口径。

## 文化

### 27. 香港艺术展改期、加场与无障碍专场

- **追踪目标**　按展览、场馆和日期记录开放时间、预约规则、加场或停展、无障碍场次以及退票安排。跟进主办方和场馆公布的版本变化，并标注变动影响的票种和场次。
- **主题类型**　文化、民生、优惠
- **排除规则**
  - 艺术评论
  - 其他城市的同名展览
  - 黄牛票
  - 没有排期变化的明星宣传
- **推荐检查**　真实模型手动核对排期，开售或加场后可设额外检查
- **通过标准**　受影响票种、日期和场次归档准确，无障碍专场与取消能区分
- **验收样例**　主办方公布原场次取消，并给出加场与退票安排。核对受影响票种、改订路径与无障碍场次是否仍保留。

### 28. 电影修复从计划公布到公开放映

- **追踪目标**　按片名和修复版本记录参与机构、公开确认的修复计划、首次放映、字幕与版本差异，以及后续档案开放或流媒体发行。区分已确认排期、节目预告和取消。
- **主题类型**　文化、科技、国际
- **排除规则**
  - 个人滤镜重制
  - 未授权上传
  - 一般影评
  - 与指定修复版本无关的票房报道
- **推荐检查**　真实模型 + Agent，批准片方、档案馆和影展节目单
- **通过标准**　同片不同修复版本分档，排期、放映、档案开放各有独立证据
- **验收样例**　档案馆公告恢复 4K 版，影展公布首次放映，随后流媒体上线了另一版本。记录各版本身份，避免把上线当作 4K 公开交付。

## 健康

### 29. 香港社区疫苗预约资格与接种点

- **追踪目标**　按接种计划记录面向公众的资格、预约起止、补贴、站点和服务时间变动。优先查核卫生机构公告，区分计划公布、预约开放、扩围及到期。
- **主题类型**　健康、民生
- **排除规则**
  - 个人病历
  - 个体用药或诊疗意见
  - 香港以外的接种计划
  - 没有公开依据的治疗传言
  - 补充剂推广
- **推荐检查**　真实模型手动检查官方公开资料，在扩围和到期前设置检查
- **通过标准**　预约资格、日期与站点一致，个人病例及治疗传言排除
- **验收样例**　公告先开放预约，后扩大适用对象并增设社区站点。确认新增资格与生效日来自卫生机构，排除个人经验帖。

### 30. 高温下的校园和户外运动安排

- **追踪目标**　跟进学校、体育场馆与赛事主办方因高温发布的官方安排。记录触发条件、受影响活动、改期和补课办法、保障措施及恢复日期，区分常态指引与某日应急决定。
- **主题类型**　健康、环境、体育
- **排除规则**
  - 个体医疗建议
  - 缺少本地关联的天气
  - 日常训练计划和技巧
  - 与高温无关的活动取消
- **推荐检查**　真实模型手动提交应急与常态规则，建立天气季定时检查
- **通过标准**　具体某日的改期、恢复与常态指引区分，活动及地区命中目标
- **验收样例**　场馆发布常态高温指引，学校随后因高温另行公布某日改期。指引与当日决定保留各自的适用范围和恢复时间。

## 课堂演示优先选题

- **从试点到上路**适合展示同一项目如何跨越测试、试行和正式开放，也能演示如何排除同品牌在其他地区的新闻。
- **街市翻新后，摊档去哪里**适合并排比较公告、新闻和实际重开范围，并展示一篇文章涉及多个摊点时如何归档。
- **极端降雨**适合演示一次事件如何串起气象预警、临时交通限制和服务恢复，以及重复报道与实质时间变动的差别。
- **电影节青年票**适合演示同一活动的票种、资格和加场通知，以及如何排除二手宣传。
- **NBA 转会传闻到官方注册**适合演示代理如何压缩已知进展，并据此判断报道只是重复、补充证据还是改变了结论。已有回放语料可用于这项演示。

## 每个示例的后续测试

用单独的测试主题先跑一轮手动检查。建议准备一条有效首报、一条同对象的新进展、一条语义重复或无关稿。对于存在冲突的主题，再加入一条来源或关键结论互相矛盾的稿件。可以优先用手动提交控制样本，也可以选一个范围清晰的公开 RSS、搜索或网页来源。

### 离线回放、提醒和定时验收

1. **离线回放**　在侧栏打开「测试离线回放」。NBA 转会例子可选 LBJ 或 NBA 语料，饮食或优惠类可另建香港麦当劳演示主题。先选最早截止时间，再逐阶段向后推进。确认时间线只使用截止前的数据，重复执行同一截止时间时没有多记同一进展。对固定输入比较 Agent 与普通模型时，各用一个新主题，保持语料和对应阶段一致。
2. **提醒策略**　建两个测试主题，对同一组能触发状态变化的样本分别选「重大进展即时提醒」和「全部进入更新汇总」。验证前者在新重大进展入库后显示站内提醒和未读，后者只进汇总。打开同一提醒并刷新，已读状态应保留。低优先级变化在前者只出现在历史，在后者进入汇总。
3. **两种定时计划**　批准一个实时来源并先手动检查一轮。在一个主题设 1 至 3 个未来时间点，确认首页「待定时更新」和主题标题显示同一时间。在另一个主题设小间隔和「从现在开始」，确认运行记录出现「定时检查」，下一次时间按间隔推进。切换右上角时区，时间显示应换算到同一时刻。可关闭浏览器后重新打开，运行记录应仍可查看。测试结束后关闭定时计划，避免继续消耗模型额度。
