# TraceRadar 主题示例

以下 30 个配置覆盖 15 个主题类型，每类两例。小节标题就是「主题名称」。新建时填入追踪目标，按列出的顺序勾选类型，第一项决定封面。创建后进入「编辑追踪目标」，把排除规则按条添加。示例写的是追踪范围，实际进展以你启用的来源为准。

## 科技

### 1. 从试点到上路：香港自动驾驶接驳

- **追踪目标**　跟进香港机场、园区及公共道路的自动驾驶接驳项目。按运营方和线路分别建档，记录试验牌照、试行区域、载客条件、班次及开放对象。区分封闭测试、限定载客试行与公众常态服务，核实首日、站点和预约方式。
- **主题类型**　科技、出行、民生
- **排除规则**　排除海外驾驶演示、车企融资、无具体路线的宣传，以及普通机场接驳服务。

### 2. 大模型推理接口上线与退役

- **追踪目标**　跟进选定模型服务的正式 API 变动。为每个模型和地区记录模型 ID、公开或预览状态、上下文与工具能力、价格、限额及停用时间。将公告、实际开放、价格生效和旧接口退役记为独立节点。
- **主题类型**　科技、财经
- **排除规则**　排除匿名跑分、聊天网页皮肤更新、第三方转售折扣，以及缺少模型或生效日期的传言。

## 教育

### 3. 大学课堂的生成式 AI 规则

- **追踪目标**　跟进香港高校与院系公开发布的生成式 AI 教学及评核规则。记录适用课程和学期、允许的用途、披露要求及学术诚信处理。把学校通则、院系细则与课程实例分开，标记征询、公布和正式实施。
- **主题类型**　教育、科技
- **排除规则**　排除学生的个人经验帖、与课程无关的企业培训，以及缺少公开规则的教师个案。

### 4. 香港中学电子学习资助与设备借用

- **追踪目标**　按学年记录电子设备资助、借用计划及配套网络支援。提取适用学校与学生、申请窗口、资助上限、设备归属及归还要求，区分全港政策、个别学校安排和机构捐赠。
- **主题类型**　教育、民生
- **排除规则**　排除零售商折扣、个人二手交易、大学研究补助和与学习设备无关的助学金。

## 出行

### 5. 一站能不能用：港铁无障碍路线复原

- **追踪目标**　按车站和出入口记录升降机加装、临时停用、预计复修及实际复用。记录受影响的行人路线、可用替代路径、服务范围及恢复时间，尤其关注宣布完工但入口仍有限制的情况。
- **主题类型**　出行、民生
- **排除规则**　排除普通车务延误、电梯品牌宣传、无车站标识的投诉，以及未影响通行的例行检查。

### 6. 夜间过海交通何时加班

- **追踪目标**　跟进大型活动和节日期间的夜间过海安排，按路线及日期记录临时尾班、加班班次、改道、上客点和费用。区分建议、官方安排、当晚调整和事后恢复。
- **主题类型**　出行、文化、民生
- **排除规则**　排除不涉及过海的普通日间班次、旅行攻略、现场照片和缺少日期的转发。

## 科学

### 7. 从发射到交付：月球任务进度

- **追踪目标**　以任务和载荷为单位跟进发射窗口、入轨、着陆、通信恢复、科学观测及公开数据交付。优先采用任务团队与航天机构发布，分开记录预计、尝试、部分成功与官方复核。
- **主题类型**　科学、科技、国际
- **排除规则**　排除太空题材影视、无任务名称的远景概念图、旧发射视频重发，以及只讨论运载商估值的报道。

### 8. 珊瑚热浪之后的复原验证

- **追踪目标**　追踪选定香港水域的珊瑚白化、恢复及监测。按站点和调查周期记录水温异常、观测方法、影响比例、复测结果和修复计划，区分目击、定量监测和同行评审。
- **主题类型**　科学、环境
- **排除规则**　排除水族交易、外地潜水游记、缺少海域或日期的照片，以及只重复同一组数据的稿件。

## 饮食

### 9. 校园与社区餐饮改用可重复餐具

- **追踪目标**　按校园、场馆或餐饮商记录可重复餐具的试点、推广、押金、归还点、洗涤安排和减废结果。把试点期、扩展期和暂停分开，并核对不同照片或新闻是否报道同一试点。
- **主题类型**　饮食、环境、教育
- **排除规则**　排除一次性纸具带货、无回收流程的环保宣传及家庭餐具推荐。

### 10. 香港预包装食品召回与结案

- **追踪目标**　以品牌、产品和批次为单位记录公开召回通知、风险类型、销售区域、退换方式、范围扩大与结案。以食物安全部门及生产商的公开通告为主要依据，同一批次的更正保留原时间线。
- **主题类型**　饮食、健康、民生
- **排除规则**　排除个人食评、未经核实的病例贴文、与香港销售无关且无进口关联的召回，以及餐厅评级。

## 法律

### 11. AI 生成内容的版权裁决与申诉

- **追踪目标**　按司法管辖区和案号追踪已公开、直接讨论生成式 AI 训练或输出的版权案件。记录程序节点、涉争问题、裁决范围、上诉或和解，并区分法院确认、当事方主张和媒体解读。
- **主题类型**　法律、科技、国际
- **排除规则**　排除无案号的舆论争议、律师营销、未公开聊天记录，以及只谈商用模型价格的内容。

### 12. 香港立法中的消费者订阅与自动续费

- **追踪目标**　跟进香港有关自动续费、取消流程和价格披露的官方咨询、修订和执法指引。按提案或规则分别记录草案、通过、生效及行业宽限期，提取对商家与消费者的具体适用范围。
- **主题类型**　法律、民生、财经
- **排除规则**　排除没有正式出处的法律解读、普通促销、多年前旧稿重发，以及与订阅收费无关的个别退款。

## 体育

### 13. NBA 转会传闻到官方注册

- **追踪目标**　按球员与交易对手分别追踪选定球队的谈判、口头协议、官方签约、体检与交易完成。记录关键条款的消息来源及可信度，保留记者报道与球队公告的冲突，区分续约、签约和多方交易。
- **主题类型**　体育、财经
- **排除规则**　排除比赛技术统计、球迷自制交易机、无新证据的旧消息引用及球鞋代言。

### 14. 香港马拉松：报名、路线与延赛

- **追踪目标**　按届次及项目记录报名阶段、抽签结果日期、名额和资格、路线变更、交通安排以及天气触发的延赛与退款。将某一组别的变化留在该组别的时间线。
- **主题类型**　体育、出行、环境
- **排除规则**　排除私人训练计划、装备测评、其他赛事和缺少赛事官方确认的封路传闻。

## 优惠

### 15. 电影节青年票真的怎么买

- **追踪目标**　跟进选定香港电影节的青年票、学校配额、会员优先购及候补返票。按活动记录优惠对象、票价、核验方式、开售和截止时间，保留售罄、加场和退款变化。
- **主题类型**　优惠、文化、教育
- **排除规则**　排除黄牛、会员推荐链接、未明确适用电影节的常驻影院折扣及过期团购。

### 16. 超市生鲜同规格优惠与会员门槛

- **追踪目标**　跟进指定香港超市公开的限时生鲜优惠。按零售商、商品规格和活动周期记录标价、单位价格、会员门槛、换购条件、渠道和适用门店，区分新申请优惠、活动延续与商品规格变化。
- **主题类型**　优惠、饮食、民生
- **排除规则**　排除个人收据传闻、第三方推广码、无商品规格的宣传及清仓但不可核实日期的转帖。

## 时政

### 17. 香港公共空间咨询怎样变成施工

- **追踪目标**　跟进指定区内海滨、行人空间或公园改造。按项目记录咨询、区议会或立法会文件、预算审批、招标、施工及交付，并提取争议点在哪次会议或修订后改变。
- **主题类型**　时政、民生、环境
- **排除规则**　排除与施工范围无关的政论、缺少官方文件的评论，以及其他区类似项目的报道。

### 18. 电子政务服务扩大覆盖的进度

- **追踪目标**　按具体服务跟进新增网上申请、试点部门、资格、身份验证方式、生效日期及线下渠道安排。按官方来源区分功能发布、地区或部门扩围、系统异常和恢复。
- **主题类型**　时政、科技、民生
- **排除规则**　排除软件供应商行销、只更新视觉设计的网页、离岸服务和未经核实的账号问题。

## 民生

### 19. 街市翻新后，摊档去哪里

- **追踪目标**　跟进指定街市翻新、临时搬迁及重开。逐市场记录停业范围、临时摊档地址、租金安排、无障碍动线、预计和实际重开日期，核对部分重开和全面恢复的差别。
- **主题类型**　民生、饮食、出行
- **排除规则**　排除商场周年活动、个人摊档食评、未获确认的拆迁图和与名单无关的零散零售消息。

### 20. 公共图书馆夜间服务与自助还书

- **追踪目标**　按分馆或站点记录延长开放时间、自助还书机试点、覆盖范围、维护停用和恢复。提取实际使用条件、账户要求和截止时间，区分节日临时安排与长期调整。
- **主题类型**　民生、教育、文化
- **排除规则**　排除商业书店活动、普通新书推荐及和开放服务无关的读者意见。

## 国际

### 21. 跨境电子支付互通到哪一步

- **追踪目标**　按地区组合与支付网络跟进试点、商户范围、参与钱包、交易币种、限额、费用和实际开放日期。区分签署合作备忘录、少量试点与面向公众上线。
- **主题类型**　国际、财经、科技
- **排除规则**　排除外汇预测、推广返现、未经证实的商户接入清单及纯投资类报道。

### 22. 跨国博物馆借展与文化遗产归还

- **追踪目标**　按馆藏编号或明确对象跟进公开的借展、归还协商、协议签署、运输、交接与展出变动。记录原持有方、接收方、期限以及官方文件确认的状态。
- **主题类型**　国际、文化、法律
- **排除规则**　排除拍卖价格、缺少对象身份的传闻、泛泛馆藏介绍及无实质进展的纪念报道。

## 财经

### 23. 上市公司并购从报价到交割

- **追踪目标**　记录一宗公开并购的首次披露、竞价或改价、股东表决、监管决定、截止期、交割与终止。优先核对交易所披露和监管公告，为不同买家或标的分开建档。
- **主题类型**　财经、法律、国际
- **排除规则**　排除目标价预测、日常股价起伏、无交易文件的匿名猜测，以及与该案无关的同行业并购。

### 24. 香港公共事业收费怎样调整

- **追踪目标**　跟进指定公共事业公布的基本收费、附加费、补助和宽限期。记录适用用户、计算方式、提交或批准时间与账单实际生效日，区分方案调整、一次性补助和长期费率变化。
- **主题类型**　财经、民生、环境
- **排除规则**　排除个别账单争议、地区不符的收费、替代产品广告和只有宏观预测的文章。

## 环境

### 25. 极端降雨：预警到交通恢复

- **追踪目标**　按一次天气过程关联公开预警、受影响区域、停课或交通限制、预警解除及服务恢复。保留时间顺序与适用范围，对多区报道去重，同时保留安排有差别的地区。
- **主题类型**　环境、出行、民生
- **排除规则**　排除旧天气图、个人气象推测、外地相似事件及没有地点和时间的现场视频。

### 26. 屋苑厨余回收从试点到常态

- **追踪目标**　按屋苑跟进回收点启用、收集时段、准入条件、处理量和设备故障。记录试点是否扩展、移动点是否撤换，并区分项目累计量、分点数量和日均数据。
- **主题类型**　环境、民生、科技
- **排除规则**　排除普通家庭食谱、无具体站点的企业宣传、旧设备投放和无实际项目的技术新闻。

## 文化

### 27. 香港艺术展改期、加场与无障碍专场

- **追踪目标**　按展览、场馆和日期记录开放时间、预约规则、加场或停展、无障碍场次以及退票安排。跟进主办方和场馆公布的版本变化，并标注变动影响的票种和场次。
- **主题类型**　文化、民生、优惠
- **排除规则**　排除艺术评论、跨城同名展览、黄牛票及没有排期变化的明星宣传。

### 28. 电影修复从计划公布到公开放映

- **追踪目标**　按片名和修复版本记录参与机构、公开确认的修复计划、首次放映、字幕与版本差异，以及后续档案开放或流媒体发行。区分已确认排期、节目预告和取消。
- **主题类型**　文化、科技、国际
- **排除规则**　排除个人滤镜重制、未授权上传、一般影评，以及与所追踪版本无关的票房新闻。

## 健康

### 29. 香港社区疫苗预约资格与接种点

- **追踪目标**　按接种计划记录面向公众的资格、预约起止、补贴、站点和服务时间变动。优先查核卫生机构公告，区分计划公布、预约开放、扩围及到期。
- **主题类型**　健康、民生
- **排除规则**　排除个人病历、临床用药意见、非香港项目、无公开出处的治疗传言及补充剂推广。

### 30. 高温下的校园和户外运动安排

- **追踪目标**　跟进学校、体育场馆与赛事主办方因高温发布的官方安排。记录触发条件、受影响活动、改期和补课办法、保障措施及恢复日期，区分常态指引与某日应急决定。
- **主题类型**　健康、环境、体育
- **排除规则**　排除个体医疗建议、没有地域关联的天气、日常训练技巧，以及和高温无关的课程取消。

## 课堂演示优先选题

- **从试点到上路**适合展示同一项目如何跨越测试、试行和正式开放，也能演示如何排除同品牌在其他地区的新闻。
- **街市翻新后，摊档去哪里**适合并排比较公告、新闻和实际重开范围，并展示一篇文章涉及多个摊点时如何归档。
- **极端降雨**适合演示一次事件如何串起气象预警、临时交通限制和服务恢复，以及重复报道与实质时间变动的差别。
- **电影节青年票**适合演示同一活动的票种、资格和加场通知，以及如何排除二手宣传。
- **NBA 转会传闻到官方注册**适合演示代理如何压缩已知进展，并据此判断报道只是重复、补充证据还是改变了结论。已有回放语料可用于这项演示。
